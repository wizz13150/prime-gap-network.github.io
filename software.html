Read the map before a long run

Big integers.
Exact boundaries.

Scout’s documented public domain is [266, 295). The lower bound is included; the upper bound is excluded. That spans 67-bit through 95-bit integers. A bit width describes the integer, not the amount of GPU memory it uses.

67-bit integers start at73,786,976,294,838,206,464295 is outside the public domain39,614,081,257,132,168,796,771,975,168

An interval may still fail a native planning constraint inside that domain: origin, boundary halo, low-64-bit window, descriptor count, or available memory. A refusal with a reason is different from silently skipping work.

Positions are not discovered primes. A positions-per-second measurement counts the integer interval traversed under a stated policy. It is not a count of primality proofs, new records, accepted PGN tickets, or network capacity.

Plan for your available time and storage. Begin with a modest supported job, understand its effective minimum-gap policy, and leave room for results, checkpoints, and optional diagnostics. Keep the package and session data together. Use acknowledged Pause when you need the machine.

Match validation to your download. A source-tree validation note may describe an older build. Check the version and the package’s own records; compilation and host tests do not demonstrate physical execution on every GPU or operating system.

Source: Scout README: exact results and compatibility, plus its range controls and validation documentation. Current release notes take precedence.

A careful first run.

This is an orientation guide. The documentation shipped with your downloaded release takes precedence over screenshots or old instructions.

  1. Choose the official package

    Use the Scout GitHub release page. Read its notes and validation record, choose the package for your operating system, and compare its SHA-256 checksum with the published file. Avoid withdrawn releases.

  2. Read the prerequisites

    Scout needs compatible NVIDIA hardware and drivers. Consult the package’s build targets and supported-platform notes. The current README describes portable Windows x64 and Ubuntu 24.04 x64 packages.

  3. Keep the package together

    Extract the full archive and preserve its libraries, worker metadata, and launchers. Use the launcher included for your platform. Installation and launcher details can change between releases.

  1. Choose a documented interval

    Read the current range and boundary constraints. Scout is independent software: a locally entered interval is not a PGN ticket or a reservation in someone else’s range register.

  2. Check the effective search policy

    Record the exact interval, release, backend, and minimum-gap policy. A minimum gap is a reporting/search threshold; a displayed merit target is not automatically the same thing.

  3. Preserve evidence as you go

    Use the application’s acknowledged pause and checkpoint workflow. Keep reports and session data together. A suspended or partial range is not completed coverage.

Guide basis: Scout README, first launch and controls. See the release’s included documentation for exact current commands.

Interpret before submitting

A result needs
its context.

Keep the lower endpoint, upper endpoint, gap size, merit convention, exact interval, threshold, software version, and verification method. Preserve any certification output the tool produces.

The Scout README distinguishes exact compositeness witnesses, deterministic primality testing within a strict domain, and bundled primality proof beyond that bound. It also explicitly warns that endpoint certification alone does not establish exhaustive coverage for the underlying probable-prime search algorithm.

Avoid a stronger claim than the evidence supports.

“The endpoint is proved prime” does not by itself mean “this is a first occurrence,” “the entire requested range is certified,” or “the network has accepted this work.”

For possible records, compare the relevant maintained tables and follow their current submission policy. Do not announce a new record from a screenshot alone.
