Background, carefully bounded

Build on knowledge.
Keep identities clear.

The public PGN repository describes a software effort that began in late July 2026 with work on Gapcoin, then broadened to Riecoin and Primecoin. Contact with Robert opened a new direction around his PGN initiative.

That background explains a collaboration. It is not evidence that PGN inherits another project’s chain, supply, software release, or scientific records.

The public presentation identifies early development, experimental software, and community discussion. This website adds clearly labelled working-design details supplied for review; it does not retroactively declare them deployed.

Direction, without
invented deadlines.

This is a proposed review roadmap for the community. No item is a guaranteed release, funded commitment, or production milestone.

NOW / REVIEW & CLARIFY

Make the foundations explicit.

Review this draft with Robert and the community. Reconcile terminology, improve the guides, and document ticket and audit invariants. Keep stable Scout downloads linked to their official source.

NEXT / TEST THE CONTRACT

Prove the workflow survives.

Exercise commitment order, partition coverage, pending-state recovery, small-miner operation, and cross-boundary accounting. Publish reproducible evidence for accepted behavior.

LATER / DECIDE WITH EVIDENCE

Measure, then commit.

Evaluate consensus and any Fabric choice, specify rewards and retargeting, and measure complete system capacity. Explore planned CPU/OpenCL support as separate software work.

Production readiness is an evidence question.

Clear consensus rules, verified state recovery, an explicit trust model, and measured capacity need to come before production or large-scale claims. Optional heavy-compute nodes remain a last-resort design possibility.

Editorial policy

Useful, attributable,
and open to correction.

Published facts: linked to primary project material, author research, or maintained mathematical records. The source inventory records what each source supports.

Working proposals: Robert’s ticket/audit/Gold model and this community roadmap are labelled as proposals. Their inclusion is not evidence that the testbed enforces every intended invariant.

Verification language: candidates, probable primes, proved endpoints, gap checks, and exhaustive coverage remain distinct. External records and current releases should be checked at their maintained sources.

No fabricated activity: this static site has no live miner count, chain data, reward feed, or search-progress service. Its mathematical figures use small, explicitly described examples.

Privacy: this draft adds no analytics, accounts, cookies, embedded third-party video players, or data-collection forms. Library search and the gap example run locally. Following an external link is subject to that service’s own policies; GitHub Pages handles hosting requests.

Corrections: open a website issue with the page, precise claim, and a reliable source. For community discussion, join the PGN Discord. Please avoid private personal information in public reports.
